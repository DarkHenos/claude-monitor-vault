# Logo for version 1.1.0

The terracotta gauge preserves recognition. The paired orange/teal shapes express
continuity between assistants; the small keyhole recalls the vault. No official
Claude or OpenAI trademark is reproduced.

- `media/logo-concept.png`: concept generated with the built-in image_gen tool.
- `media/logo-companion.svg`: clean, editable vector interpretation for production.
- `icon.png`: Marketplace icon, 256 pixels.
- `media/logo.png`, `media/logo-128.png`: 512 and 128 pixel renditions.
- `media/activity-bar.svg`: monochrome VS Code theme-aware rendition.
- `media/icon-legacy.png`: previous icon, retained as a source reference only.

Run `npm run build:logo` to regenerate PNGs from the production SVG. The renderer
is a development dependency and is excluded from the extension package.

## Built-in generation prompt

Create a final polished square app icon for a VS Code extension named Claude Monitor & Vault + ChatGPT. Output exactly one standalone flat logo, no text or letters, no brand sheet, no mockup. Original symbol combining a bold open semicircular usage gauge with two opposing simple linked rounded strokes meeting in a subtle keyhole-like central negative space: monitoring, secure vault, continuity between assistants. Retain the recognizable warm terracotta-orange #D97757 gauge arc of the old extension, introduce one restrained muted teal #62B5A5 stroke for the new assistant. Strong simple geometry, uniform rounded thick strokes, only 3 or 4 structural elements, central balanced composition with generous 12% margins. Flat vector-like rendering, perfectly crisp silhouette readable at 32 pixels, no gradients, no shadow, no 3D, no texture, no official Claude or OpenAI logo. Transparent background, square 1024x1024 canvas. This is a new icon concept that stays familiar to existing users through the terracotta semicircular dial.
